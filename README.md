# A畜伴侣：Claude 中英双向翻译

一款适用于这台 Mac 的菜单栏小工具。主要适配 Claude 桌面版和浏览器中的 `claude.ai`。

## 打开

从源码取得项目后，先在项目目录运行 `./build.sh`，再双击 `dist/A畜伴侣.app`。菜单栏会出现「A畜伴侣」。默认使用苹果系统翻译，无需填写 API 密钥。首次使用可能需要下载中英文语言包。

自动回填和读取回复需要系统的辅助功能权限：在A畜伴侣点击「前往开启」，进入「系统设置 → 隐私与安全性 → 辅助功能」，开启「A畜伴侣」。如果列表中没有该应用，点击加号，选择 `dist/A畜伴侣.app`。

## 写中文，发送英文

1. 点击 Claude 的聊天输入框。
2. 按 **Control + Option + E**，打开A畜伴侣。
3. 输入中文。按回车提交，按 Shift + 回车换行。中文输入法选字时的回车不会提交。
4. 英文会自动填入原来的输入框。默认由你检查后手动发送。
5. 如需直接发送，打开「填入后发送」，按 Claude 的设置选择「回车」或「⌘ + 回车」。

工具会检查原输入框和光标位置。翻译过程中修改目标输入框、关闭窗口或改变焦点可能导致回填停止，英文会保留供复制。无法核实粘贴结果时不会自动按发送键。发送键已按下不代表服务端已成功接收，请以 Claude 的显示为准。

## 自动看中文回复

默认开启「自动译回中文」。通过A畜伴侣填入后，工具等待识别到你真正发送的消息，再监测该会话中的新回复。

回复文字连续约 3 秒没有变化时，A畜伴侣会将其译成中文，显示在同一个聊天页面里。Claude 后续补充内容时会再次更新译文；短暂停顿不代表回复已经最终完成。

- 中文消息与中文回复连续显示，底部输入框用于继续交流。
- 显示回复时不会主动抢走 Claude 的输入焦点。
- 可以展开英文原文，或复制中文。
- 点击「停止读取」可停止监测；关闭主窗口也会停止读取。点击垃圾桶只清空本工具的显示，不删除 Claude 中的会话。
- 切换 Claude 会话或无法确认消息结构时，监测会停止。重新在目标输入框按快捷键即可选择目标。
- 如果你想翻译已有的最新回复，在 Claude 输入框按快捷键后点击「读取当前回复」，即可读取当前会话并继续等待新回复。
- 如果回填后又手动改变了英文消息，工具无法可靠核对本次发送，会停止自动绑定；可在发送后使用「读取当前回复」。

## 翻译设置

点击右上角齿轮，可选择系统翻译，或填写自己的 OpenAI 兼容服务地址、模型和 API 密钥。密钥保存在 macOS 钥匙串中。使用 AI 翻译时，你输入的中文及读取到的 Claude 回复会发送到你配置的服务；费用按该服务规则收取。

默认不保存消息历史。仅在运行期间保留当前草稿与最多 40 条本地显示的消息。停止监测会释放对话绑定，清空本地对话会清除显示内容。工具会临时使用剪贴板回填，并在剪贴板仍属于本次操作时恢复原内容。

## 适配范围

目前针对 Claude 的「Chat messages / Message … / You said: / Claude responded:」可访问界面结构识别回复，不使用整页文字差异猜测回复内容。Claude 界面变更、超长或被虚拟化的历史、某些工具卡片、嵌入式输入框可能导致识别停止。遇到提示时可使用「仅翻译」与复制功能。

系统翻译支持 macOS 15 及以上。首次英译中也可能显示语言包准备提示。本次交付针对当前的 Apple Silicon Mac / macOS 26 测试。Chrome 中的 Claude 与 Claude 桌面版是主要验证对象，其他浏览器没有同等验证。

## 当前验证进度

在 Apple Silicon Mac / macOS 26.6.2 上，36 项核心测试、4 项原生编辑器测试、12 项回复识别与翻译状态测试和 5 项本机 HTTP 集成测试通过。本机模拟对话已验证英文回填、发送和第一条英文回复自动译成中文。

系统翻译准备和回复翻译各有 120 秒超时；翻译中可以取消，取消、超时或失败后会结束等待状态并提供重试。真实 Claude 会话中的连续多轮端到端流程尚未完整验证，更新后的超时与取消界面也仍需按 `TEST_PLAN.md` 实测。请结合测试计划理解当前覆盖范围；本项目尚未通过所有场景的验收。

## 构建与测试

```sh
./build.sh
./test.sh
./test-http.sh
./build-fixture.sh
```

`dist/A畜伴侣测试输入框.app` 是本机模拟对话，只用于验证回填、发送和自动回复翻译，不连接 Claude，不向任何人发送消息。

应用使用本地临时签名。重新编译后，macOS 可能要求重新开启辅助功能权限。当前版本没有配置开机启动，也没有后台常驻网络服务。
