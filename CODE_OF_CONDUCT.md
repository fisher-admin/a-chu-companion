# Code of Conduct / 社区行为准则

## 中文

我们希望使用者和贡献者能够礼貌、平等地讨论问题，不论经验、身份、背景或使用语言。

- 讨论具体问题，尊重不同意见，用清楚的复现步骤和证据帮助协作。
- 不接受骚扰、歧视、侮辱、威胁、人身攻击或未经允许披露他人私人信息。
- 不公开登录凭据、私人聊天或能够识别他人的敏感材料；截图请先脱敏。
- 本准则适用于仓库 Issue、Pull Request、讨论和与本项目有关的公开交流。

维护者可要求修改不当内容、关闭讨论，或限制持续违规者参与。处理时结合具体行为及影响，不以不同技术观点本身作为处分理由。

发现违规行为，请在 GitHub [维护者个人页](https://github.com/fisher-admin) 提供的联系渠道私下联系；不要公开受影响者的细节。如果涉及安全漏洞，使用 [私密安全报告](https://github.com/fisher-admin/a-chu-companion/security/advisories/new)。如暂无合适私密联系渠道，可提交不含私人细节的联系请求，等待维护者提供渠道。

## English

Treat users and contributors with respect regardless of experience, identity, background, or language. Discuss concrete problems, disagree constructively, and provide reproducible evidence.

Harassment, discrimination, insults, threats, personal attacks, and disclosure of private information without permission are not accepted. Do not post credentials or private conversations; sanitize screenshots. These expectations apply to issues, pull requests, discussions, and public project-related communication.

Maintainers may request edits, close discussions, or restrict participation after considering the conduct and its impact. Technical disagreement alone is not a reason for enforcement.

Use contact channels on the [maintainer profile](https://github.com/fisher-admin) to report conduct concerns privately. Do not expose affected people's details. Use [private security reporting](https://github.com/fisher-admin/a-chu-companion/security/advisories/new) for vulnerabilities. If a private contact channel is unavailable, request contact without posting personal details.
