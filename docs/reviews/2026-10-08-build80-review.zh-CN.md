# Claude 基于 build78 的优化审核：1.2.1 build80

审核日期：2026-10-08。审核对象为本机 `streaming-on-build78` 分支提交 `f105d18ad5d73f5850dec489d70da703b8063410`。

## 评价

这次优化的基础和取舍是正确的，明显优于此前从旧主分支改写的 1.2.0：以 build78 为直接父提交，保留三端手选输入、原生网页额度、独立 Gemini、表格保护、中文界面识别和每段单独显示。没有重新加入用户已取消的翻译质量审核、输入区内容检查或发送确认门槛。

主要优化有实际价值：稳定段落提前翻译、云翻译最多三段并行且按序显示、系统翻译串行，以及密钥被拒绝后暂停重复请求。原来的 42 组测试没有删改，新增了一组针对这些改动的测试。

但独立补测复现了三处新增问题：空白思考回复误报界面故障、大量分段在重复读取后重新翻译并替换最新记录，以及合法引号被清理掉。因此，这版适合作为下一步修订的基础，尚不宜直接认定为正式稳定版本。

## 已复现的问题

### 1. [P2] 有作者标记但正文为空，会误报“界面结构已变化”

位置：`Sources/ReplyCore.swift:621–625`，告警由 `Sources/ReplyMonitor.swift` 处理。

判定结构异常时，代码检查的是是否能解出完整消息，而非是否识别到了作者标记。一个有 `Claude responded:` 标记、正文暂时为空的正常思考卡片，也无法解出完整消息。当可读取的消息区只有这张卡片时，就被判为结构异常。

独立复用现有 `ReplyTests` 的空白思考卡片，连续等待 46 秒，结果如下：

```text
THINKING_PENDING_STRUCTURAL=true
THINKING_46_SECONDS_FALSE_INTERFACE_WARNING=true
THINKING_READING_STILL_ACTIVE=true
```

影响：读取没有真正停止，但界面会显示错误原因、建议用户重连，并将检查间隔延长至三秒。与 README 和变更记录中“思考不会触发”的说法不符。

建议：分别识别“作者/消息结构已找到”和“正文已可读取”；前者成功、后者尚未就绪时按正常等待处理。补测必须从真实解码流程产生等待状态，而不是直接构造 `structural: false` 的错误对象。

### 2. [P2] 固定只记 512 个已移出记录，会让仍可见的旧分段重新进入

位置：`Sources/Core.swift:136–153`；该列表用于显示记录、读取监测和翻译队列三层。

新实现按数量丢弃最早的“已移出记录”标识，假定它们已经离开可读取范围。但 Code 的多个分段可共享同一个消息序号；限制最近的消息序号，并不能限制该消息包含多少分段。

独立模拟一条包含 600 个已完成短分段的 Code 回复，共 16,692 字符，仍低于 50,000 字符上限。第一次读取后显示第 591–600 段。再次读取完全相同的内容，结果为：

```text
LONG_STAGES_FIRST_REQUESTS=20
LONG_STAGES_FIRST_HISTORY_COUNT=10
IDENTICAL_SECOND_SNAPSHOT_EXTRA_REQUESTS=20
IDENTICAL_SECOND_SNAPSHOT_EXTRA_SCROLL_REVISIONS=590
LONG_STAGES_SECOND_VISIBLE=581–590
LONG_STAGES_PIPELINE_RECORDS=10
```

影响：记录总数仍是十条，内存数量测试也能通过，但最新十段被更旧的十段替换，重复产生翻译请求和滚动更新。这是大量分段边界下的问题，并不表示普通三十轮对话也会出错。

建议：保留内存上限，但应依据会话、消息和分段的读取范围淘汰去重信息；不要仅按 512 个标识先后删除。可用已淘汰的序号/分段范围进行压缩，并保留手动历史翻译的明确例外。补测重复同一份多分段回复，要求请求数、记录顺序和滚动位置均不变化。

### 3. [P2] 原文与译文使用不同引号时，合法引号会丢失

位置：`Sources/TranslationCleanup.swift:40–42`。

清理逻辑只判断原文是否以译文的同一种引号开头。英文直引号变成中文弯引号，本来是正常翻译，却会被当成模型额外包裹。

独立输入原文 `"Hello."`，译文 `“你好。”`，清理后的实际结果是 `你好。`。

影响：引文、字面表达或引用短语的格式会被改变。清理多余说明的方向合理，但不能把原文已有的引用结构一起删掉。

建议：统一识别成对引号的语义；原文已被任何支持的成对引号包裹时，保留译文对应的引号。新增直引号、中文弯引号及日文引号之间转换的测试。
