# A畜伴侣：Claude 中文与多语言双向翻译

一款适用于这台 Mac 的菜单栏小工具。主要适配 Claude 桌面版和浏览器中的 `claude.ai`。

![A畜伴侣应用图标](assets/companion-icon.png)

猪头中央 A 的彩色图标按照本机 Claude 桌面版 2.19675.0 应用包内图标取色：主橙色 `#D9704E`，背景由 `#D97757` 轻微渐变到 `#DB6944`，猪头为 `#FAF9F5`。[Anthropic 官方品牌配色](https://github.com/anthropics/skills/blob/main/skills/brand-guidelines/SKILL.md)中的基础橙色是 `#D97757`；本机应用图标带有更深的渐变。窗口与应用图标同步使用校准后的配色；菜单栏保留随系统外观适配的单色图标。

## 打开

首次从源码安装，在项目目录运行 `./setup-signing.sh`，再运行 `./install.sh`。正式使用 `~/Applications/A畜伴侣.app`，菜单栏仅显示猪头中央 A 的图标，点击它即可打开工具。默认使用苹果系统翻译，无需填写 API 密钥。首次使用某种语言可能需要下载对应语言包；已经安装的语言包由 macOS 保留，重启和升级伴侣会复用，不重复安装。主窗口标题区随 macOS 浅色／深色外观变化，采用原生半透明磨砂材质，输入及回复区使用更通透的玻璃；系统开启减少透明度时使用不透明背景。

自动回填和读取回复需要系统的辅助功能权限：在A畜伴侣点击「前往开启」，进入「系统设置 → 隐私与安全性 → 辅助功能」，开启「A畜伴侣」。如果列表中没有该应用，点击加号，选择 `~/Applications/A畜伴侣.app`。

运行期间每秒自动检查权限，正常开启后提示会自动消失，无需退出重开。撤销权限也会更新提示。检测只查询本工具是否获授权，不会反复弹出授权窗口或自动发送消息，草稿和当前聊天内容会保留。

## 更新与授权

正常更新运行 `./install.sh`，继续打开同一个安装位置。安装程序先检查签名身份，关闭本工具、构建并校验新版本，再替换正式应用。原有安装与更新的签名身份不一致时会停止；构建失败时保留原有正式安装。

本机固定签名的私钥保存在登录钥匙串中，不可导出，仅允许系统签名工具使用。公开的证书指纹与钥匙串位置保存在 `~/Library/Application Support/AChuCompanion/signing.json`。这些本机资料不会上传到仓库。重复运行签名设置会复用原证书；证书或私钥缺失时不会悄悄生成替代身份，也不会退回临时签名。

固定签名使正常启动、重新编译和本机升级继续使用同一个身份。第一次从临时签名转换为固定签名时仍需重新确认辅助功能权限。删除授权、丢失证书私钥、换电脑或改变应用身份后，也可能需要再次确认。不要在更新时删除原签名证书。此签名用于本机身份连续性，不等同于 Apple 的公开发行签名。

## 写中文，选择对方语言

1. 点击 Claude 的聊天输入框。
2. 按 **Control + Option + E**，打开A畜伴侣。
3. 在“中文 ⇄”菜单选择英文、德文、日文或韩文，再输入中文。按回车提交，按 Shift + 回车换行。中文输入法选字时的回车不会提交。所选语言自动保存，重启和正常升级后沿用。
4. 所选语言的译文会自动填入原来的输入框。默认由你检查后手动发送。
5. 如需直接发送，打开「填入后发送」，按 Claude 的设置选择「回车」或「⌘ + 回车」。

工具会检查原输入框和光标位置。翻译过程中修改目标输入框、关闭窗口或改变焦点可能导致回填停止，译文会保留供复制。无法核实粘贴结果时不会自动按发送键。发送键已按下不代表服务端已成功接收，请以 Claude 的显示为准。

## 自动看中文回复

连接 Claude 后立即开始持续读取，不必先从伴侣发送消息。连接提示旁显示「停止读取」；只要不停止，在伴侣或 Claude 原窗口输入产生的新正式回复都会被读取并译回中文。连接时也会翻译当前最新的完整回复。

Claude 思考、调用工具和生成中的停顿不算完成。伴侣结合生成结束提示、停止生成按钮和正式回复操作区判断完成，再等待正文稳定约 3 秒。先显示完整原文，再更新同一条气泡中的中文。工具活动、运行提示和操作按钮排除，正式正文中的代码保留。临时读不到文字时持续等待；权限撤销、连接窗口关闭或离开 Claude 页面时停止并提示。

- 同一个连接窗口切换到另一段 Claude 会话时，自动跟随当前会话。其他窗口的消息不会混入。发送目标仍需核对：切换会话后需要重新连接输入框才能回填，避免发错对话。
- 新用户消息不会打断前一条已完成回复的翻译；多条回复按顺序处理，同一回复改写时更新原来的气泡。
- 停止读取后，普通发送、取消输入翻译和清除记录都不会重新启动自动读取；「开始读取」或再次连接可恢复。
- 切换到其他程序、Claude 被其他窗口遮挡时，持续读取保持运行，不要求 Claude 或伴侣一直处于前台。保持已连接的会话窗口打开；网页版需保持该 Claude 页面可访问。
- 关闭主窗口只隐藏伴侣，持续读取保持运行；退出程序才结束读取。
- 显示回复不会抢走 Claude 的输入焦点。自动发送完成且你仍停留在目标软件时，焦点返回伴侣；只填入未发送时，保留目标输入框供确认。
- 系统翻译分别显示读取原文、检查语言、准备和分段翻译进度；失败、取消或超时保留原文，支持重试。macOS 26 已安装的语言直接启动系统翻译，未安装语言使用原生下载流程。

## 历史回复与本地记录

在 Claude 中滚动到需要翻译的历史消息，点击伴侣的「读取历史回复」。只读取当前连接窗口可见的完整正式回复；有多条时列出原文预览供选择，有一条时直接翻译。历史读取不会重新开启已停止的自动读取，也不会把整段历史自动翻译一遍。若窗口中没有可见的完整回复，会提示你滚动到目标消息。

中文译文默认字号为 **14**；聊天区上方提供「小 12／中 14／大 16」，短消息和长阅读区同步改变，语言与字号选择都会在重启、正常升级后保留。原文和输入框采用各自字号。

伴侣只保留最近 **10 条已完成的 Claude 中文译文**，仅在本次运行中存在，退出后清空。重新翻译已有记录会更新该条并移到最近位置，不创建重复记录。聊天区上方的「清除记录」只清除伴侣记录，保留正在写的草稿，不删除 Claude 会话，也不停止持续读取。

## 长文字与字数上限

中文输入最多提交 **10,000 字符**；发出的外语译文和读取的 Claude 外语原文最多 **50,000 字符**，英文、德文、日文、韩文统一按字符计算。标点与换行计入字数。超限时保留中文草稿或 Claude 中的原文并提示，不直接截断，不填入或发送半截译文。缩短草稿后可继续提交。

两种翻译方式都会按自然文字边界分段，显示进度，全部完成后合并；发送时仍作为一条消息填入并只触发一次发送。AI 服务明确拒绝单段过长或返回截断结果时，会自动缩小分段重试。每段独立计时，整个长任务不会因为总时长超过两分钟而被取消；失败或取消时不提交半截译文。

长回复显示后从气泡及正文开头阅读，侧边滚动条用于向下查看。超过 8,000 字符的正文使用独立的原生阅读区，完整保留文本，支持选择与“复制全文”。正文更新时回到开头；正文未变化时保留阅读位置。自动读取采集绑定会话的最新八条消息；手动历史读取按可见位置选择，均核对窗口、会话、作者和完整正文。

Claude 的消息大小、上下文额度、所选服务规则和系统资源仍然存在。即使文字符合伴侣的上限，外部服务仍可能拒绝。工具不会擅自拆成多条消息发送。

## Claude 账户额度

名称右侧显示 Claude 套餐，刷新、连接额度和翻译设置集中在右上角，五小时及每周额度采用进度条＋已使用百分比，并保留重置时间。缺失的数据不画成 0%，旧数据仍标记。点击「连接额度」后优先选择「读取 Claude 桌面登录」；首次可能需要允许本程序读取 Claude Safe Storage 钥匙串项。它只读桌面端当前会话和组织，不修改 Claude 的登录、密码或 cookie 数据库。后续自动查询禁止弹出授权提示，正常升级继续同一签名；如果权限被撤销或登录失效，会显示连接提示。

也可输入已有额度监控工具使用的 `sessionKey` 和组织 UUID。session 单独存入本工具的 macOS 钥匙串，不写配置、日志或仓库。查询只向 `https://claude.ai` 发送只读额度与组织信息请求，不打开网页、不调用模型、不消耗聊天额度；禁止重定向、共享 cookie 和磁盘响应缓存。该接口与当前 Claude 桌面版使用的接口一致，但属于产品内部接口，后续变更可能需要适配。

收到稳定的新回复或补充内容时会刷新，翻译失败或超出字符上限仍触发刷新；启动已连接的工具和点击刷新按钮也会查询。账户切换会清除旧值并丢弃旧请求结果。暂时失败保留上次结果并标记旧数据，会话失效清空结果；缺失的额度不显示为 0 或无限。重置时间按本机时区显示，可悬停查看来源、组织与读取时间。浏览器聊天与桌面端使用不同账户时，请用该聊天账户的 session 连接。

套餐根据账户实际能力识别 Pro、Max、Team、Enterprise、Free。根据 [Claude 官方 Max 说明](https://support.claude.com/en/articles/11049741-what-is-the-max-plan)，Max 也有五小时与每周限制，只是额度更高；不按套餐名称硬编码隐藏五小时限制，始终以返回的限制为准。

## 翻译设置

点击右上角齿轮，可选择系统翻译，或填写自己的 OpenAI 兼容服务地址、模型和 API 密钥。保存新设置会结束旧配置下的翻译任务，持续读取保持运行，随后使用新设置。密钥保存在 macOS 钥匙串中。使用 AI 翻译时，你输入的中文及读取到的 Claude 回复会发送到你配置的服务；费用按该服务规则收取。
