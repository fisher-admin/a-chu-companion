# A畜伴侣 1.2.0 / AChu Companion 1.2.0

2026-10-08 · build79 · 正式源码发布 / Formal source release

## 中文

本版正式发布 Claude 优化分支的流式翻译与故障降级。苹果系统翻译仍是默认方式，支持中文与英文、德文、日文、韩文双向转换；选择 AI 翻译后，超时、限流、权限错误或校验失败会逐段改用系统翻译。

主要变化：

- 读取到的原文先显示，可翻译句段按原文顺序逐步更新。
- 已完成翻译并行处理，保留围栏代码，取消和原文改写后隔离旧结果。
- 持续无法识别 Claude 页面约 45 秒后给出提示，恢复后继续读取。
- AI 连续失败暂时停用，并遵守服务端等待时间；系统翻译不可用时保留原文。
- 发布整理补齐本机文件排除与凭据扫描，保留版本历史、独立审核和未验证项。

### 版本来源与已知限制

**正式发布状态不代表以下已知问题已经修复。**

本版来自 2026-10-03 的 main 基础，原优化提交为 build29；正式构建号接续已存在的 build78 使用 79。build78 开发分支及其全部提交单独保留，没有被本次版本整合。

1. 本版没有 build78 的 Claude Code CLI 支持、原生网页额度读取、独立 Gemini 配置和专用表格显示。额度来源为桌面登录或手填 session；不同客户端的账户不能直接视为相同。
2. 网页 Code 路径及非英文界面消息标记存在读取适配缺口。本版没有完成真实桌面 Chat/Code、网页 Chat/Code、不同终端 CLI 或真实 Gemini 的验收。
3. 完整阶段段落位于原文末尾、后续文字尚未到达时，可能延迟开始翻译；完成分段合并在同一气泡显示。
4. 较长表格行和行内代码可能被拆开翻译；长译文追加可能把阅读位置移回顶部。
5. AI 语言与长度等质量检查仍存在，可能拒绝保留算法名称的正常技术译文。通过 AI 兼容地址使用 Gemini 时，应重新核对配置；旧的独立 Gemini 配置不会自动迁入。
6. 通用 AI 密钥没有按服务地址隔离。更换地址前应更换对应密钥，避免沿用另一服务的密钥；不要把“发送成功”提示当作服务器已接收的证明。
7. 界面最多显示十条完成译文，但后台回复缓存尚未同步裁剪。超限回复保留原文，但不会触发额度刷新。

具体复现与后续整合顺序见[独立审核报告](../reviews/2026-10-08-claude-1.2.0.md)。

### 验证与安装

本机验证包括 273 项离线检查、7 项本机 HTTP 检查、7 项仓库工具检查、完整历史凭据与文档检查、无签名构建，以及英德日韩真实系统翻译。实际执行记录见 [TEST_PLAN](../../TEST_PLAN.md)，GitHub CI 独立显示远端结果。测试通过不覆盖上述已知问题。

适用于 Apple Silicon Mac；最低编译目标 macOS 15，主要在 macOS 26 验证。macOS 15 实机、Intel Mac 和其他浏览器未经同等验收。

GitHub 自动提供此标签的源码 ZIP/TAR。按 [README](../../README.md) 创建自己的本机签名并安装；不分发维护者本机签名包、密钥或会话，也不把 CI 无签名验证包当作公证安装包。

```bash
git clone --branch v1.2.0 --depth 1 https://github.com/fisher-admin/a-chu-companion.git
cd a-chu-companion
./setup-signing.sh
./install.sh
```

## English

This formal source release publishes the streaming translation and automatic fallback work. macOS system translation remains the default, supporting Chinese with English, German, Japanese or Korean. Optional AI translation falls back per segment on timeouts, rate limits, authorization errors or failed output checks.

Changes include original-first display, ordered incremental translations, cancellation and rewrite isolation, verbatim fenced code in the reply pipeline, a recoverable interface warning after approximately 45 seconds, AI cooldown with server retry timing, and restored repository credential checks and local-artifact exclusions.

### Scope and known limitations

**Formal release status does not mean these known issues are fixed.**

The optimization started from the October 3 main branch and was originally build29. Formal build79 continues the existing counter after build78. The build78 development branch and its commit history remain separate; this release does not incorporate all of its features.

- CLI support, native web usage acquisition, dedicated Gemini configuration and table rendering from build78 are absent. Usage supports desktop login or a manually supplied session; do not assume different clients share an account.
- Web Code routes and non-English message markers have reading gaps. Real desktop Chat/Code, web Chat/Code, multiple-terminal CLI and Gemini acceptance were not completed for this release.
- Stable trailing paragraphs may wait for later text before translation; completed segments share one bubble. Long table rows or inline code may be split, and appended translations can reset the reading position.
- AI output quality checks can reject faithful technical translations containing algorithm names. Existing dedicated Gemini settings do not migrate automatically to this release's OpenAI-compatible configuration.
- The generic AI key is not scoped per endpoint. Replace the corresponding key when changing providers. A send confirmation is not proof of server receipt.
- The UI retains ten completed translations, but backend reply caches are not trimmed with it. Oversized replies preserve their original but do not trigger usage refresh.

The [independent review in Chinese](../reviews/2026-10-08-claude-1.2.0.md) documents reproductions and the integration plan.

### Verification and installation

Local verification covers 273 offline checks, 7 loopback HTTP checks, 7 repository-tool checks, full-history credential and documentation checks, an unsigned build, and real system translation for English, German, Japanese and Korean. See [TEST_PLAN](../../TEST_PLAN.md); GitHub CI separately reports remote results. These passing checks do not cover the known issues above.

Apple Silicon is the build target. Deployment targets macOS 15; primary validation uses macOS 26. Actual macOS 15, Intel and other browsers have not received equivalent validation.

Install from the tag's source archives using the commands above and your own local signing identity. Maintainer-signed local bundles, keys and sessions are not distributed. CI verification bundles are not notarized end-user installers.
