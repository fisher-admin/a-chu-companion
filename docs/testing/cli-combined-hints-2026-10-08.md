# build73：CLI组合提示连接修复

## 已核实的原因

用户报告build72在真实macOS终端按快捷键仍不能连接。伴侣显示已见一个底部会话标记和一个输入标识，但输入区核对失败，证明快捷键已到达。

用户随后提供终端截图：当前输入区显示推荐文字，底部提示为`⏵⏵ auto mode on (shift+tab to cycle) · ← for agents`。截图中的个人目录及本机会话标记未纳入测试和版本库。

旧规则仅接受单独的模式提示，既不识别agents提示，也不能识别同一行组合；即使会话、进程和窗口正确，仍在页脚提示核对处拒绝。使用合成会话标记还原相同布局，新增输入用例先出现6项失败；菜单与运行提示专项先出现2项失败。不是重新授权能解决的问题。

## 最小修订及通过条件

逐个核对最多三个已知快捷提示，新增精确的`← for agents`及同一模式的实心三角符号。沿用会话／进程／窗口／焦点、完整译文接收与重复粘贴检查；未知提示、普通shell行、权限选择和混合输入不自动发送。菜单读取使用同一提示规则，避免放宽页脚后将选择光标当成消息输入框。

本次完成条件：截图布局可绑定；推荐文字不阻断；短文完整粘贴后可按设置回车一次；未知尾随提示和shell仍拒绝；相同底部提示不遮挡独立的菜单及运行提示；沿原签名安装并打开更新版。

## 验证边界

离线合成输入、原生模拟窗口和正式安装分别记录。真实终端截图证明当前布局，但不能作为修复安装后已连接或已发送的证据。本轮不再次尝试工具已禁止的真实Terminal界面访问，也不使用脚本代读／代输入。

日志、旧程序备份及合成原生事件计数保存在本机忽略目录`.build/optimization73/`。此前build72的完整35组与真实连接失败均保留。本轮只重跑受影响的CLI输入、操作提示和连接路由，不将旧全量结果标成build73全量重测。
