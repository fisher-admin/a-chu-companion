# build74：手选输入位置与三端统一发送

日期：2026-10-08。版本：1.1.8 build74。原版本 build73 保存为 `62b7571`，原安装备份位于本机忽略目录；所有旧提交、成功、失败和真实验收待确认项保持。

## 当前规则

用户在需要的输入位置按 Control＋Option＋E，立即保存当前应用、窗口和输入组件。桌面、网页及CLI都调用同一个发送实现：翻译完成后恢复所选位置，发送一次粘贴按键；开启「填入后发送」时再发送一次回车。不开启时只粘贴。单行、多行、表格和折叠显示均采用同一规则。

发送不检查译文含义、数字、问句、语言、长度比例、是否附加解释、输入建议、CLI尾部提示、当前输入值／光标或粘贴回执。删去语义审核模块、拼接后审核、表头译文的语义替换及质量核对提示。保留10,000字符输入与50,000字符原回复限制、代码和表格格式处理、仅翻译指令、服务超时／空白结果及备用系统翻译。

发送位置和读取身份独立保存。读取报告迟到、停止读取或更换读取来源不会解除、替换发送连接。CLI底部身份只关联所选表面的回复与额度来源，不决定能否发送；没有匹配报告时也可以发送。实际失效的窗口／输入组件和无法恢复的物理焦点会给出具体错误，不搜索另一窗口。连接只在本次运行内有效，不跨重启保存辅助功能对象。

取消、更换发送连接或编辑中文草稿不会把旧任务自动改投其他位置。粘贴按键已发出、回车失败时报告部分完成，不重复粘贴。界面仅报告按键已发出，不宣称目标软件已收到或服务器已回复。
