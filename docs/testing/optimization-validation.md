## 不从模拟结果推出的结论

新方案的自检、浏览器扩展、CLI 桥接、profile 迁移、流式翻译和增量 UI 尚未实现。本轮未证明它们通过 54 项验收，也未测量实际 Claude 阶段性输出到中文的 P95。后续每个批次先增加能暴露现有问题的检查，再改动并重跑对应回归。

新增阶段性翻译模拟应覆盖：A 段稳定后立即自动提交并返回中文、B 段尚未出现时 A 的中文已经可见、整轮完成不重复重译、繁忙队列逐块调度、失败后明确重试及旧片段不回填。仅“候选可译”或“原文已显示”的测试不能代替这些完整时序断言。

本次要求澄清后的文档核对：仓库检查通过（112 个当前文件、283 个历史 blob），54 项原编号完整且唯一；25 个源码及 2 个原有未提交文档摘要仍与初始基线一致。仅修改设计与测试安排，未新增生产功能或执行上述新增阶段性模拟。
