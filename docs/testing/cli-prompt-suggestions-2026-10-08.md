# CLI推荐提示文字修订

基线为build70、`dcb41a9`。用户实体快捷键连接后，正式伴侣显示“CLI输入区已有文字，未覆盖草稿”。用户说明这是Claude Code的建议内容，输入会自然覆盖，要求不因有显示文字而阻止连接或填入。已从伴侣界面只读核对到该错误；未读取或操作真实Terminal。

## 原因与修订

CLI的辅助功能文字包括输入区的灰色推荐内容，无法仅凭是否有文字判断真实草稿。[Claude官方说明](https://code.claude.com/docs/en/interactive-mode#prompt-suggestions)确认开始输入会消除推荐文字。

旧代码在绑定、发送前、译文回填前及实际粘贴前均要求显示内容为空。build71移除该条件，继续核对原进程、窗口、焦点、会话和输入标记；直接按CLI正常粘贴逻辑输入译文。推荐文字由CLI自行消除，不使用清空快捷键或终端滚屏选择。

粘贴后仍要求实际输入与译文完整一致，才按设置自动回车。若旧文字与译文混合、截断或不可核对，不自动发送。用仅在本次运行保留的摘要记录已经尝试的粘贴，原输入未改变时不重复粘贴；正常发送完成后释放记录。
