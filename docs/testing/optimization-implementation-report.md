## 实施结果与边界

本轮完成确认方案的首轮范围：原文不等待上一条翻译；正式稳定段自动进入翻译，中文按切片回传；同一回复原位更新，保留已译前缀和阅读位置；接口密钥隔离、被动状态检查、结构保护、可见额度来源和主动启用的只读桥接均有实现。

最重要的时序模拟把 A 段放在 0 秒，3 秒确认稳定，3.2 秒显示 A 的中文；B 段在 12 秒出现，整轮在 36 秒结束。断言同时检查中文确已回传和整轮仍未完成。这个结果证明调度规则，不是对真实 Claude、Apple 或云服务速度的承诺。

慢翻译期间的新原文立即可见；长段第一块完成后立即发布，下一稳定段能在上一长段的切片之间获得翻译机会。后缀变化只重译受影响部分；最终完成不重译已完成块。服务限流按返回的等待时间恢复，主动取消保持暂停直至重试；失败保留原文及已译中文。

语言和字号偏好继续保存；运行内保留最近 10 条已译回复，预览、用户草稿另有数量预算。清除和淘汰使旧任务失效，晚到结果不能复活；主动读取历史可重新选择对应条目。翻译内部切片不新增历史条目，Code 正式分段仍单独显示。

兼容服务凭据和模型按规范化接口来源保存，旧密钥只在原绑定来源安全迁移；Gemini 原生接口、固定模型和独立密钥保留。OpenAI/Grok 预设不自动选择模型或换供应商。代码围栏、含嵌套反引号的行内代码、URL、明确路径、命令选项和占位符在本机保护，不靠模型保留特殊标记。

CLI/Chrome 桥接默认关闭，需主动启用、明确选择来源；输入仅翻译或复制，不向任意终端发送回车。浏览器仅请求 `claude.ai` 和 Native Messaging 所需权限，没有 Cookie、debugger 或全站权限。CLI 默认只接 statusLine，MessageDisplay 需确认实际版本支持后明确启用。临时目录安装、三方卸载、重放、缺序、导航代次、帧大小及权限校验均有模拟。

可见 Usage/statusLine 不根据套餐名称猜五小时窗口，不把缺失窗口写成 0，不合计不同来源。连接活性和额度证据时间分开；确认账户及新证据后才能迁移，迁移先停旧来源；配置损坏不会自动回读旧登录。当前正式程序的额度连接未迁移。

状态检查按权限、来源、语言/云配置、密钥和可选入口独立显示。密钥检查只查询来源对应的本机元数据，禁止授权交互、不读取密钥正文、不迁移密钥；锁定或权限不足表示待验证而非缺失。免费政策内置核验日期和 [Google](https://ai.google.dev/gemini-api/docs/pricing)、[OpenAI](https://developers.openai.com/api/docs/pricing)、[Grok](https://docs.x.ai/developers/models) 官方链接，不自动打开网页或推断账户余额。唤醒只合并被动检查，不抢焦点。

AX 加整体时间和节点预算，暂时未采齐继续等待而不结束监测。AXObserver、SSE/NDJSON、托管 CLI 发送、Azure/DeepL、远程政策服务按方案后置；未实现项不写成模拟通过。API 账单与 gateway 金额仍不在范围内。
