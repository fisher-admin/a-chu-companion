## 2. 项目结构理解

- **发送链**：`TranslatorModel.begin` → `TextTranslation.runProtected`（按表格/代码/段落分块）→ Gemini/兼容 AI/系统翻译 → `TargetBridge.refresh` 核对窗口、会话、内容、光标 → `deliver` 剪贴板粘贴、核对粘贴结果、可选回车。
- **读取链**：`ClaudeSource`（辅助功能树，每秒一次）或本机桥接（Chrome 扩展 / CLI 钩子）→ `ReplyPipeline` 按片段稳定 3 秒后翻译、前缀复用、版本号防迟到 → 历史最多 10 条已完成译文。
- **额度链**：桌面读取 Claude 桌面登录；网页由扩展同源请求；CLI 由 statusLine 报告。`ClaudeUsageMonitor` 以来源、绑定、代次、序号和账户指纹隔离，身份不明即隐藏旧值。

## 4. 优化方案

### 4.1 纯翻译保护（F1–F3，优先）

在所有翻译方式共用的 `TextTranslation.piece` 增加确定性核对，不依赖某一服务商：

1. **加权长度上限**：按文字体系折算长度（汉字≈3、假名≈1.6、谚文≈2.2、拉丁字母=1），再按目标语言设上限（英/日/韩约 2.0 倍、德语约 2.5 倍，回译中文约 1.8 倍，另加固定余量照顾短句）。校准结果：忠实译文 0.4–1.94 倍；附加一段答案 2.4–6.5 倍。
2. **新增结构**：原文没有而译文出现表格、标题、列表或代码块，直接拒绝；该检查在“合并换行”之前进行。
3. **问句保持**（英/德）：原文最后一句是问句而译文结尾不是问句，拒绝。
4. 拒绝时不填入、不发送，中文草稿保留，提示“疑似附加了回答”；回复方向保留原文并可重试。
5. 提示词采纳候选中的具体示例，但**暂不启用 JSON 结构化输出**，待一次真实“测试连接”验证接口接受后再决定。

局限会如实写明：短小的附加答案仍可能漏过；这些规则不证明语义忠实，语义仍需真实样本复核。

回归测试：重建的失败样本（英/德）、附加表格、附加标题；对照组为四种语言的忠实长译文、德语短句扩展、成语意译、问句与否定句、数字与代码保留，并确保现有 429 项不受影响。

### 4.2 临时故障恢复（F4–F6）

- 503/500/超时/断网：每个片段自动重试最多 2 次（间隔约 2 秒、6 秒），仍失败才标记失败；429 继续按服务要求等待。
- 一个片段失败时，状态明确显示“第 N 段失败”，并保持后续原文可见。
- 超时与断网分开提示。
- 读取失败改为逐步放慢重试（1→2→4→8 秒，上限约 60 秒），而不是 5 次后停止；用户仍可手动停止。

### 4.3 发送确认（F7，可选）

回车后在短时间内核对输入框已清空或内容已变化；不能确认时提示“请以 Claude 显示为准”，绝不重发。
