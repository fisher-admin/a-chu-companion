# 多语言、长文本与磨砂玻璃升级

目标：中文是唯一输入与回复显示语言，发送对象可选英文、德文、日文、韩文；猪头中央 A 为应用图标，菜单栏仅显示图标；主窗口使用 macOS 原生半透明磨砂材质。

完成标准：四种语言的双向配置与 AI 指令正确；超出旧 12,000／60,000／90,000 字限制的代表性内容通过；分段不漏字、不损坏 Unicode，失败或取消不会提交半截译文；长任务按每段计时；过大的 AI 单段可自动缩小；长页面只读取绑定对话消息。原有权限、目标和重复发送保护保持有效。图标在菜单栏小尺寸可辨识，正式包有应用图标；原生窗口实际查看、选择语言、翻译并验证授权保留。

1. Core.swift：取消输入硬限制，定义四种目标语言与双向指令，修复回译指令中的英文输出矛盾。CoreTests.swift 先重现旧限制和指令错误，再覆盖每种语言。
2. TextTranslation.swift：共享自然边界分段、保留空白、逐段翻译、进度、取消和每段超时。仅针对超大请求与截断自动缩小片段。Tests/TranslationPipelineTests.swift 验证超过 100,000 字的完整往返、截断恢复、失败不返回半截、取消和超时。
3. TranslatorModel.swift、ReplyMonitor.swift：保存所选语言，每个任务锁定语言。双向系统翻译与 AI 翻译都走分段流程。切换语言结束旧读取，保留历史与草稿；每个消息记录原文语言。
4. ClaudeAccessibility.swift、ReplyCore.swift：消息区定位与正文读取分离，只读取最新消息，取消字符总量限制；保留会话验证、结构保护、取消和单次 AX 调用超时。ReplyTests.swift 验证历史滚动、改写历史、切换会话与长回复。
5. CompanionIcon.swift、Tools/GenerateIcons.swift、build.sh：绘制可缩放猪头 A 图标，生成应用 icns；菜单栏无文字。GlassBackground.swift、Main.swift、Views.swift：原生磨砂背景、适应明暗外观、语言选择与准确文字标签。
6. 运行核心、翻译管线、回复、权限、原生输入、HTTP 与签名检查；使用本机模拟会话和正式新版做实际验证。保持固定签名，安装到同一位置，同步仓库。

不自动拆成多条 Claude 消息。译文完整合并后只回填并触发一次发送；Claude、系统语言包、API 服务和可用内存本身的限制不能被工具承诺为无限。保持取消、完整性核对和真实错误提示，不以删除保护来制造“无限”假象。

验证记录：107 项自动检查通过；四种语言的实际双向系统翻译通过；140,032 字回复实际译回中文，保留 4,000 个段落与最终标记；117,023 字中文在界面完成 40 段翻译并显示 467,996 字英文。原超长 SwiftUI 文本导致卡顿，已切换为完整的原生阅读区；多条长消息展开滚动后仍发现 LazyVStack 排版循环，最终交付前继续修复并验证连续使用。

用户最终决定：中文提交上限 10,000 字符，外文原文和译文上限 50,000 字符，四种外语统一计数；超限保留原文并提示，不截断。替代最初不限长度的目标。自动化须覆盖边界与边界加一、Unicode 字符计数及恢复；实际界面测试新上限与重复长消息、取消及展开滚动。原生阅读区保持完整正文。LazyVStack 改为稳定 VStack，聊天修订序号合并无动画定位；阅读区明确尺寸，仅在变化时更新样式。

最终验收：114 项自动检查通过；四种实际系统双向翻译与 49,031 字符长回复通过，保留 1,400 个段落及末尾标记；界面内 10,001 字符被拦截，缩短草稿后 9,677 字符生成 38,709 字符英文，展开、滚动、取消、再翻译正常，进程恢复空闲。正式包继续同一签名和路径，权限未重置。真实 Claude 新消息完整往返仍按测试安排由用户验证。

新增范围：名称右侧增加 Claude 当前套餐、五小时／全模型周用量与重置时间；每次稳定新回复刷新。用户明确不用网页读取，优先桌面登录会话，提供指定 session 备选。当前官方安装包 2.19675.0 内的 Pli / hfn 函数核实只读 `/api/organizations/{uuid}/usage?skip_spend=1` 和组织 capabilities；同包现行 limits(session,weekly_all) 及 legacy five_hour/seven_day 的 utilization/resets_at 双格式。桌面 plan-usage-history 仅有百分比历史、无 reset，不能作为完整实时来源。不会驱动 Claude 设置或用 Codex 额度工具。官方 Max 文档确认 Max 同样有五小时限制，按返回窗口显示。

完成标准：最小只读桌面 cookie 读取、域名校验、钥匙串授权仅显式连接时允许弹窗；手动 session 仅存本工具钥匙串；请求仅官方 HTTPS、拒绝重定向、无模型调用、无日志秘密；并发刷新合并、账户切换和旧结果隔离、网络失败旧值标记、401 清除；完整解析、会话解密独立夹具、模拟 HTTP 和回复触发测试；正式界面查看两行位置、连接入口和已有授权。真实账户额度读取需用户允许新的 Claude Safe Storage 项访问，不自动点击系统授权。

新增验证：6 个解析／只读请求测试、8 个额度整合测试和 1 个回复触发测试通过；本轮当前代码共 118 个 test.sh 检查以及 7 个真实本地 HTTP 检查通过。只读真实桌面会话检查因新程序没有 Claude Safe Storage 访问权停止，未显示或保存凭据。macOS 随后锁定，1.1.1 安装等待钥匙串签名操作，最终安装／界面／真实额度对照等待用户解锁；不得把这些项标记为完成。
