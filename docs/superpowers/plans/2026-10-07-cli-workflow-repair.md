# CLI连接与译文复制修复实施计划

> 按用户已授权的三端优化及本次问题修复执行，主执行者在当前工作区逐项复现、修改和验收；不启动并行执行，不重写历史。沿用已批准的只读CLI设计，终端输入由用户确认，不增加自动终端回车。

**目标：** 多会话可明确区分，终端连接快捷键进入正确选择流程，最新与历史外文译文均可直接复制；不依赖终端程序品牌。

**依据：** build67界面实际只有两项六位编号，缺少复制按钮；`copyOutput()`存在但未调用；清空草稿会清空临时output，而历史气泡没有复制操作。`prepareTarget()`失败或未知输入只显示原生连接错误，不打开CLI选择。会话绑定同时使用session_id与cwd，工作目录改变会生成额外来源。

**设计：** 不通过任意终端屏幕或进程猜测当前会话。CLI底部增加与伴侣一致的来源编号，保留原状态栏输出；选择页显示目录末级名称、模型、报告时间和正文是否已收到。绑定仅依据唯一session_id，升级时只迁移精确匹配的旧当前目录／原项目目录状态，并保留已失效身份的隔离。终端快捷键只请求并显示候选，用户明确选择；不自动选最新或唯一来源。

**技术范围：** SwiftUI主界面与模型、已认证的本机桥接协议、Python官方statusLine适配。目录仅取末级名称，不传递完整路径、转录路径或原始账户信息。未知输入是选择入口，不被当作已确认Claude来源。
