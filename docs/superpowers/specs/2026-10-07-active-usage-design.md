# 连接聊天时自动连接额度

用户最新要求：额度跟随当前 Claude 聊天来源自动连接；设置只补充安装、手动获取和故障恢复。已有授权覆盖本轮实现及测试，不新增通用审批或发布。

桌面绑定成功即无弹窗读取当前桌面登录；需要钥匙串时提示一次，不循环弹窗。网页/CLI 选择桥接来源时先隐藏上一来源额度，等待该绑定的新身份和报告，自动采用通过核对的结果。不得从其他来源回退；用户停止桥接后取消跟随。

网页入口在启用的官方 claude.ai 标签内用浏览器原有会话执行同源只读 GET；不读取 Cookie、token、聊天以外的浏览记录。官方公开脚本已确认 /api/account 返回账户和 memberships；仅唯一组织时自动请求对应 usage?skip_spend=1，多组织不猜测。前后两次核对邮箱及组织，变化则丢弃并清除旧额度。私有网页接口结构变化需明确失败。只向本机传递遮蔽名称、指纹和限额。原 DOM 采集不能证明身份时不冒充成功。

CLI 使用官方 SessionStart/auth status/statusLine；设置按钮安装包装器，保留原输出和无关设置；获取按钮改变仅本工具所有的状态栏命令以触发新报告。状态栏定时重复报告不能宣称服务器刷新；额度缺失显示未提供。无需读 OAuth 或新增钥匙串访问。旧会话换号永久隔离。

网页获取请求通过已认证 socket 的确认响应传到 native host，再到扩展；仅支持只读获取，不加入发送、执行脚本或任意 URL 命令。唯一请求去重，限时等待，恢复/停止使旧任务失效。

完成标准：三端有可操作设置入口，聊天绑定自动获取匹配额度；测试失败/缺身份/换号/缺窗口不串号、不显示假 0；模拟、安装版与真实服务结果分别记录。受工具禁止的终端、扩展管理、系统授权不绕过；未实测浏览器明确待验收。保留全部历史，不提交推送。
